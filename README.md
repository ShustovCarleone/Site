# ShuGhost website

The official ShuGhost website with a black and red animated design.

Included features:

- Ukrainian, Russian, and English language switching
- Desktop Gremlins and Dr. Violet game pages
- Screenshot gallery
- Our Streamers page with local avatar images and hover previews
- Anonymous live online and total view counters with Railway Volume persistence
- Official community, support, contact, and privacy links
- Responsive desktop and mobile layouts

## Preview locally

Run:

```powershell
npm start
```

Then open `http://localhost:3000`.

## Publish with GitHub Desktop and Railway

1. Add this folder as a local repository in GitHub Desktop.
2. Commit all files and publish or push the repository to GitHub.
3. In Railway, deploy the service from that GitHub repository.
4. Railway will use `npm start` and the configuration in `railway.json`.

The server listens on Railway's `PORT` automatically.
